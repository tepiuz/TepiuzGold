# Changelog

## 1.0.0

- Show recorded character balances and an account-wide total in Blizzard's backpack tooltip.
- Display full character names, including surnames, beside race icons and Blizzard's gold, silver, and copper icons.
- List the current character first, highlight its name, and sort other characters by name.
- Record balances on login and money changes, and retain the last valid balance after leaving the world.
- Upgrade older first-name-only entries when the character next logs in.
- Add settings to delete a stored character or clear all stored balances, with confirmation for both actions.
